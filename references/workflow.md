# 执行流程：从查历史到定一步行动

## 第一步：内部时间线（事实）

**要查的来源，两边都看**：
- 邮件：收件箱和已发送都看。已发送用来判断我们回过没有、最后一封是谁发的。
- 内部沟通：IM 单聊和群聊、会议纪要、日历。
- CRM：商机、报价、订单。
- 售后：工单、技术周报。
- 销售跟踪表。

**整理成一张表**：

| 日期 | 事件 | 来源 |

每行写清楚：
- 谁做了什么。
- 关键处摘一句对方原话（保留原始语言），尤其是付款争执、抱怨、承诺这类话。
- 来源写到能复查的程度，比如邮件主题、表格名、群名。

**最后一行一定要回答两个问题**：现在是谁在等谁？等了多久？
- 例："10-14 我方发信约见，到 11-09 没有回复；日历里也没有这场会，判断会面没有发生。"
- 用了"判断"的，要写出依据，比如"检索了 1,270 封邮件，命中 0 封"。

**金额和价格**：只引用内部口径或标注"见保密表"，不写进可能外传的段落。

**用原始记录核对上游摘要**：跟踪表、战役卡、周报这类二手摘要，要拿邮件和聊天原文逐条核对。对不上的地方，在结论里单独列出来，并建议由谁改。

## 第一步半：判断是哪一类跟进

不同类型的跟进，开头和问题都不一样。先判断属于哪一类，再往下做：

| 类型 | 特征 | 邮件的开口 | 重点问什么 |
| --- | --- | --- | --- |
| ① 对方不回 | 我方发过信，对方没有回音 | 用对方的公开进展开头，没回音的事一句带过 | 换人了吗？方案变了吗？请对方转给合适的人 |
| ② 交付后冷却 | 订单已交付，双方都没有新动作 | 用"我们的产品在你那里卖得或用得怎样"开头 | 现场反馈、他们的规划、下一批的预测 |
| ③ 我方欠账 | 我方答应过的事还没做到，比如固件、返还、资料 | 先主动交代进展 | 先把欠的事说清楚，再谈新需求 |

一个客户可能同时属于几类，比如 ② 加 ③：先交代欠账，再问规划。

## 第二步：卡点（为什么停了）

按下面五类逐一检查，有几条写几条。每条标明是**事实**，还是 **Agent 判断 / 我的判断**：

1. **需求信号**：最近一次询价、报价、样机、项目是什么时候？没有新信号，就直接写"没有需求信号"。跟踪表里占位的预测数字，不能当真。
2. **联系方式**：是不是发错了人？是不是回在了旧线程里，对方当成旧事没看？该抄送的采购或技术对接人有没有抄送？
3. **对方的变化**：换人、换方案（比如改用自研设备或竞品）、组织调整、被收购。
4. **商务风险**：以前有没有付款、交期、质量上的争执？这些由决策人定，不写进邮件。
5. **时间**：按交期倒推，现在拿到订单还赶得上目标期吗？赶不上就直说，例如"只能计订单口径""转入明年跟踪"。

## 第三步：公开信息和关联点（外部）

搜索对方公司最近的新闻、产品发布、招聘、展会、融资等公开信息。每条记录都标注：
- 信息来源（URL 或出处）。
- 核对状态：已打开原文 / 仅标题 / 未核对。

找出与我们业务的关联点。典型关联方向：
- 对方新发布的产品用了我们同类产品或互补方案。
- 对方扩了团队，产能或需求在增长。
- 对方提的问题恰好是我们之前帮别的客户解决过的。

**排查风险**：查对方是否跟竞品签约、是否被收购、关键人是否离职。

## 第四步：定一步行动

不是"保持跟进"，是具体的一步：

| 要素 | 要求 |
| --- | --- |
| 谁 | 我方发起人（写真实姓名，不是"销售团队"） |
| 哪天 | 具体日期，不是"本周" |
| 发给谁 | 收件人（至少列两个方案，各写风险） |
| 抄送谁 | 抄送人及理由 |
| 发之前确认 | 需要跟内部谁确认什么 |
| 没回音的后手 | 比如"5 个工作日后电话跟进" |
| 止损点 | 什么情况下转入其他客户或明年跟踪 |
